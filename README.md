# 今日メモ

当日一日のやることを素早くメモして、チェックして消化するための iPhone 向け PWA です。
昨日の残り、曜日指定の定型タスク、手動の並べ替え、直近30日の振り返りを備えた最小構成の TODO アプリです。

- ビルド不要（バニラ JavaScript の ES Modules ＋ HTML ＋ CSS）。外部ライブラリ・CDN・Web フォントは使いません
- データはすべて端末の localStorage に保存され、外部には送信されません（送るのはアクセス解析のページ表示情報のみ。設定でオフにできます）
- 初回読み込み後は、オフラインでも全機能が動きます
- 対象：iOS 17 以降の Safari（ブラウザ／ホーム画面起動）。PC ブラウザでも最低限動作します

## ファイル構成

```
index.html / manifest.json / sw.js
config.js            アクセス解析の設定（1 か所のみ）
count.js             GoatCounter の公式スクリプト（同梱、ISC ライセンス）
css/                 スタイル
js/                  アプリ本体（storage.js が localStorage への唯一の入口）
icons/               アイコン（icon.svg から生成した PNG）
tests/               ロジックと PWA 設定の確認用テスト
README.md / TESTING.md
```

## 公開手順（GitHub Pages）

1. GitHub で新しいリポジトリを作成し、このフォルダの内容を push します。
2. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 数分後、次の URL で公開されます。

   ```
   https://<ユーザー名>.github.io/<リポジトリ名>/
   ```

すべてのパスは相対パスなので、サブパス配下でそのまま動きます。
Service Worker は HTTPS でのみ動作するため、iPhone 実機の確認は GitHub Pages に push して行います。

### アクセス解析（任意）

[GoatCounter](https://www.goatcounter.com/) のアカウントを作成し、発行されたコードを `config.js` の `GOATCOUNTER_CODE` に設定します。
空のままなら、解析は一切送信されません。コードはリポジトリ内で `config.js` の 1 か所にだけ書き、他のファイルやドキュメントには書かないでください。

送信するのはアプリ起動時の 1 回だけで、パスは固定値です。ハッシュやタスクの内容は送りません。設定で「アクセス解析を送信しない」をオンにすると、`count.js` 自体を読み込みません。

## ホーム画面への追加（iPhone）

1. Safari で公開 URL を開きます。
2. 共有ボタン → **ホーム画面に追加** → **追加** をタップします。
3. ホーム画面のアイコンから起動します。

> Safari で開いた場合とホーム画面から起動した場合とで、保存データは別になります。
> 移行するときは、元の側で設定の「エクスポート」を実行し、移行先の側で「インポート」します。

## 更新時の手順

Service Worker はキャッシュファーストでアプリ本体を返すため、ファイルを変更したら**必ず版数を上げます**。

1. `sw.js` の `VERSION` を上げる（例：`'1.0.0'` → `'1.0.1'`）。キャッシュ名は `dailytodo-cache-v<VERSION>` になります。
2. `js/version.js` の `APP_VERSION` を **同じ値** に上げる（設定画面に表示されます）。
3. ファイルを追加・削除した場合は、`sw.js` の `PRECACHE` の一覧も更新する。
4. `node --test tests/` で、版数の一致とキャッシュ一覧の漏れがないことを確認する。
5. push する。

利用者側では、新しい版が見つかると「更新があります（タップで再読み込み）」が表示されます。タップすると新しい版に切り替わり、古いキャッシュは自動で削除されます。

## 開発メモ

- ローカルで確認するには、このフォルダで任意の静的サーバーを起動します（例：`python -m http.server 8000`）。`localhost` では Service Worker も動作します。
- テスト（Node.js 20 以降）：`node --test tests/`
- 日付またぎの確認用に、URL に `?debug=1` を付けて開くと、設定画面に「今日の日付を上書き」が表示されます。手順は [TESTING.md](TESTING.md) を参照してください。
- localStorage のキーは `dailytodo:` で始まります。表示名を変えてもデータは引き継がれます。
